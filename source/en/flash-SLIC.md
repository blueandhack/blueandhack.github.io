Yesterday I went over to a classmate's place to help install Windows 7<!-- more -->

To get a perfect activation, I flashed the hardware itself, and in the end everything went smoothly!

I used Lenovo's Windows 7 OEM image

It took me a long time of searching on the BIOS Home forum to find it

Flashing the BIOS and SLIC 2.1 is easy

Just run Gigabyte's official @BIOS program

Then update with that G31MES2C_F8 file and you're done~

G31MES2C_F8 includes both the BIOS update and SLIC 2.1

Wait for the update to finish

Reboot

Check that the BIOS and SLIC 2.1 were flashed successfully

Then install Windows 7

The tragic part was their optical drive, truly a tragedy~ a drive from 2006~ talk about slow read speeds~

In the end it installed fine and activated fine~

I didn't take any screenshots, so no pictures~~ 

 

Note: this SLIC 2.1 table can import multiple OEM certificates
