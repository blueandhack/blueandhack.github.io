I've had my own self-hosted blog for about 6 months now, and so far I haven't posted anything about tinkering with wordpress. So let me talk about the plugins my wordpress uses.<!-- more -->

Here's my plugin list, in alphabetical order, with download links: 

[Akismet](http://akismet.com/)         Blocks spam comments. No need to say more about this one~   

[All in One SEO Pack](http://wordpress.org/extend/plugins/all-in-one-seo-pack/)         SEO optimization. Tons of people say you need it, tons of people say you don't, uh~ I'm confused~ so I've never removed it   

[Comment Info Detector](https://web.archive.org/web/20100714205227/http://www.hzlzh.com/comment-info-detector/)         Shows each commenter's location, browser and operating system. Very cool. I'm using a modified version   

[Clean Archives Reloaded](http://wordpress.org/extend/plugins/clean-archives-reloaded/)         A very handy plugin for displaying post archives   

[Delete-Revision](http://wordpress.org/extend/plugins/delete-revision/)         Deletes redundant post revisions. Very useful. You don't need to keep it enabled, just clean things up every so often   

[Executable PHP widget](http://wordpress.org/extend/plugins/code-to-widget/)         Lets you add PHP code directly in sidebar widgets. Very handy, though also a bit of a "nice but not really needed" thing   

[Fluency Admin](http://wordpress.org/extend/plugins/fluency-admin/)         An admin dashboard makeover plugin, recommended by the BOSS of SHOWBLOG. Once you use it, your dashboard looks really slick!   

[Google XML Sitemaps](http://wordpress.org/extend/plugins/google-sitemap-generator/)         Google sitemap generator. This one is a must!   

[Hacklog Highslide Picture](https://web.archive.org/web/20100724203837/http://www.ihacklog.com/wordpress/plugins/hacklog-highslide-picture.html)         A modified image display plugin   

[Highslide4WP](http://wordpress.org/extend/plugins/highslide4wp/)         Enhances emoticons in comments   

[Highslide for Wordpress *reloaded*](http://wordpress.org/extend/plugins/highslide-4-wordpress-reloaded/)          Image zoom plugin   

[Mail To Commenter](http://wordpress.org/extend/plugins/mailtocommenter/)         Email replies to comments. Since my blog theme doesn't support threaded comments, this one is great, and it keeps users coming back!   

[NextGEN Gallery](http://wordpress.org/extend/plugins/nextgen-gallery/)         Photo gallery. It's too bloated, so it's turned off for now and I'm using a different gallery   

[OpenID](https://web.archive.org/web/20100721204501/http://lanbing.org/1913.html)         Not enabled for regular users yet. It lets people log in quickly. I recommend reading this post by Lanbing   

[Page Links To](http://wordpress.org/extend/plugins/page-links-to/)         Makes a page link straight to another URL. Very handy, no need to edit the source code   

[Post Layout](http://wordpress.org/extend/plugins/post-layout/)         Ad insertion plugin. Makes it easy to insert ads into posts   

[SyntaxHighlighter Evolved](http://wordpress.org/extend/plugins/syntaxhighlighter/)         A very powerful code plugin, though my blog also has a built-in code plugin   

[Thumbnail For Excerpts](http://wordpress.org/extend/plugins/thumbnail-for-excerpts/)         Plugin for showing thumbnails, disabled for now   

[Wibiya Toolbar](http://wordpress.org/extend/plugins/wibiya/)         Very cool tools, removed for now   

[WordPress Mobile Pack](http://wordpress.org/extend/plugins/wordpress-mobile-pack/)         Plugin for mobile access   

[WordPress Related Posts](http://wordpress.org/extend/plugins/wordpress-23-related-posts-plugin/)         Related posts plugin. [Master willin's version can do this too, a modified version by zwwooooo](http://zww.me/archives/25166)   

[wp-comment-warrior](http://wordpress.org/extend/plugins/wp-comment-warrior/)         Top commenters list, disabled for now   

[WP-Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef)         Tag cloud with Chinese support. I've optimized it to support Chinese text and the YaHei font, with no jittering. The original version doesn't support Chinese, and some versions jitter. Here's the download link for the 3D tag cloud: [click here to download from 115 cloud drive](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef)   

[WP-MulticolLinks](http://wordpress.org/extend/plugins/wp-multicollinks/)         Splits the blogroll into columns so the links don't take up a lot of space. CSS could do this too, but I'm lazy   

[WP-PageNavi](http://wordpress.org/extend/plugins/wp-pagenavi/)         Pagination plugin. It improves on wordpress's default pagination   

[WP-reCAPTCHA](http://wordpress.org/extend/plugins/wp-recaptcha/)         Comment CAPTCHA plugin. It's way too powerful, so I don't dare use it. People would curse me out if I did   

[WP-RecentComments](http://wordpress.org/extend/plugins/wp-recentcomments/)         Sidebar recent comments plugin, with ajax enabled, mainly to go with my theme   

[WPVN - Username Changer](http://wordpress.org/extend/plugins/wpvn-username-changer/)         Plugin for changing the super admin username, mainly for 2.9.2. You don't need it in 3.0

That's it. I'm still on 2.9.2, so there aren't many compatibility problems and everything works fine. Some plugins might have issues in 3.0. Let's all share what we find~
