I think this has to be the coolest tag cloud effect I've ever seen: a super flashy WordPress tag cloud built with Flash+JS. I only found it while aimlessly browsing, clicking one link after another until I ended up there. Turns out something like this exists, and it's well worth recommending. What does it look like? Check out my sidebar. **Best of all, the version I'm using fully supports Chinese!** <!-- more -->

![WP-Cumulus in action](https://cdn.blueandhack.com/wp-content/uploads/2010/08/image_thumb8.png)

Main features of the **[WP Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef)** ****WordPress plugin: 

1. The cloud can contain **tags or categories,** or both.
2. **Supports widgets and custom template code.**
3. **Doesn't affect search engine crawling.** The tag cloud it generates is only displayed visually as 3D Flash, but the source code it produces is the same as WordPress's default tag cloud. If you don't have Adobe _Flash_ Player _ActiveX_ installed, it just shows up as an ordinary tag list.

How to use the **[WP Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef)** **WordPress plugin**: 

1. Upload and activate it.![Setting up WP Cumulus](https://cdn.blueandhack.com/wp-content/uploads/2010/08/image_thumb9.png)
2. Click Appearance, then Widgets. A list of available widgets will appear; pick [WP-Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef) from it.![Setting up WP-Cumulus](https://cdn.blueandhack.com/wp-content/uploads/2010/08/image_thumb10.png)![WP-Cumulus](https://cdn.blueandhack.com/wp-content/uploads/2010/08/image_thumb11.png)
3. Drag WP-Cumulus into the sidebar next to it and configure it.![WP-Cumulus options in detail](https://cdn.blueandhack.com/wp-content/uploads/2010/08/image_thumb12.png)

  ---

- Since the settings screen can't be translated into Chinese (a character encoding problem), I can only give translations of the English here. Width and height set the size it's displayed at in the sidebar
  
- Tag color, second color, highlight color, background color, and whether the background is transparent: just set these to match your theme!
  
- Rotation speed. This version of [WP-Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef) has been modified, so it doesn't have the jittery rotation some versions of [WP-Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef) floating around online have. It spins very smoothly
  
- Whether the tags are spread evenly over the sphere: change this to suit your situation~
  
- Tags, categories, or both: where the displayed items come from. Set this one to suit your situation too~
  
- The last option takes wp_tag_cloud parameters, which let you set things like how many tags the cloud shows and the largest and smallest font sizes. Of course some parameters can't take effect, such as orderby, order and so on
  
  The effect [WP Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef) creates really is great. Put a Flash tag cloud like this on your blog and it's guaranteed to catch visitors' eyes. Best of all, [WP-Cumulus](https://web.archive.org/web/20100920113825/http://u.115.com/file/f49b5d84ef) only loads a 7KB swf, so it definitely won't slow down your page load! Beauty and speed?
