This theme is my very first theme (version 1.0.0). To avoid anyone else "wearing the same outfit," I didn't release it while I was using it~~ I only gave a beta version to a buddy to try out. Today it's officially released to the public.  <!-- more -->

The main features of this theme: 

1. Related posts and more posts built into the theme, no plugins needed
   
2. A scrolling background
   
3. A draggable Tabber widget that uses a tab effect to show recent comments, recent posts and popular tags
   
4. An archive page template with one-click collapse effect (no plugin)
   
5. A guestbook page template with a "comment wall" effect (no plugin)
   
6. Some CSS3 effects, such as rotating images, text shadows and so on
   
7. Master willin's plugin-free email notification for comment replies, plus AJAX comments
   
8. Reply to comments with @ XXX
   
9. A sliding "back to top" button on the left
   
10. Lazy-loading images
    
11. And more (for you to discover)
    
    That's about it for the theme's features. This theme passes W3C validation, both HTML 1.0 and CSS 2.1. Since the CSS3 effects are written in with JS, they don't affect validation. I also minified the JS and kept a backup: all.bak.js is the backup JS file. If you want to change anything, edit the code in there and then minify it again. This theme has no admin options page, so please edit the source code yourself. This theme is licensed under the GPL, and the header background uses an image from proclouds.
